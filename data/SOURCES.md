# 数据与素材来源

| 内容 | 来源 | 说明 |
|---|---|---|
| 曲库快照 `maimai_songs.json` | [diving-fish maimai DX 查分器 API](https://www.diving-fish.com/api/maimaidxprober/music_data) | 国服曲目元数据（标题、艺术家、难度、定数、BPM）。应用启动时会自动刷新，也可删除后重新抓取。 |
| 视频入口 | B 站搜索链接 | 不保存、不抓取任何视频文件。 |
| 在线播放 | YouTube 官方嵌入（`youtube-nocookie.com`） | 仅加载官方播放器，不下载音频。 |
| 背景图 `data/bg/` | `work/gen_bg.py` 程序化生成 | 原创，随项目以 MIT 发布。 |
| 初音插画 `data/miku/` | `work/gen_miku.py` 程序化生成 | 原创，非官方立绘，随项目以 MIT 发布。 |
| BGM `data/bgm/` | `work/gen_bgm.py` 纯标准库合成 | 原创电子乐，随项目以 MIT 发布。 |
| 角色立绘 `data/sprites/` | 原创绘制 | 原创，随项目以 MIT 发布。 |
| 名言 / 攻略 | 手工整理 | 仅作引用与学习用途，版权归原作者。 |
